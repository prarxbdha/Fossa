# Milestones

1. **Skeleton** — workspace, Tauri app, React shell, and engine module layout.
2. **Parsing** — HTML tokenizer/parser producing a DOM tree and CSS parser producing style rules.
3. **Layout and paint** — box tree construction and display list generation from a styled DOM.
4. **Rendering** — canvas painting, hit testing, and text metrics.
5. **Browser shell** — tabs, history, navigation, and loading local fixtures.
6. **Networking** — HTTP fetching, redirects, and caching.
